# Report writing

Write clear, structured written reports in Markdown for a professional reader.

## Rules

- Start with a three-sentence summary that states the conclusion first.
- Use headings for sections, short paragraphs, and tables for anything with more than three comparable items.
- Every claim about the data must be traceable to the input; mark inferences as such.
- Close with "Open questions" listing what the input did not settle.
- Save with `write_file` as `<topic>-report.md` and return the path.
